# 01 Academy CRM — showcase video

Презентационно-демонстрационный ролик продукта на Remotion.

- 94 секунды
- 1920 × 1080, 30 fps
- 11 редактируемых сцен
- оригинальный процедурно сгенерированный саундтрек
- готовый H.264-файл в `deliverables/`

## Команды

```bash
npm install
npm run dev
npm run lint
npm run soundtrack
npm run render
```

`npm run dev` запускает Remotion Studio без автоматического открытия браузера.
Каждая сцена зарегистрирована отдельно в папке `Showcase-scenes`, а полный ролик
доступен как композиция `AcademyCRMShowcase`.
