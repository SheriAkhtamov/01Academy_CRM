# Проверка управления групповым чатом

Проверка выполнена координатором самостоятельно. В этой боковой беседе пользователь запретил использование агентов, поэтому независимое агентное одобрение не заявляется. Браузер не использовался.

## Повторный проход исходного кода и сценариев

- CHAT-01 — закрыто: заголовок является keyboard-accessible button с aria-haspopup=dialog; список остаётся в Dialog, предыдущий ChatSheet сохраняется Sheet.
- CHAT-02 — закрыто: сообщения содержат senderAvatarUrl, сервер выбирает текущую фотографию через LEFT JOIN users. UI использует общий UserAvatar с безопасным URL и fallback; имя удалённого автора сохраняется.
- CHAT-03 — закрыто: операции управления повторно проверяют членство и права после FOR UPDATE группы. Руководитель CRM должен состоять в группе. Обычному участнику управление недоступно; сервер отклоняет подмену прав и чужой groupId.
- CHAT-04 — закрыто: удаление и выход выполняются через destructive ConfirmDialog. Отмена не вызывает API; ошибка сохраняет подтверждение открытым. Переименование защищено guard несохранённых изменений.
- CHAT-05 — закрыто: создатель при выходе выбирает действующего преемника из участников. Проверка/смена администратора/выход находятся в одной транзакции. Обычный участник не может менять администратора. Последний участник может выйти, история и группа сохраняются.
- CHAT-06 — закрыто: событие изменения получает объединение прежнего/нового состава. UI убирает группу и её кэш при выходе или при исчезновении членства из обновлённого списка. Отправка повторно проверяет членство после совместимой блокировки группы, закрывая гонку с удалением.
- CHAT-07 — закрыто: добавляются только действующие неархивные сотрудники, максимум 100 участников, повторяющиеся ID исключаются. Уже существующие read cursors сохраняются; новые участники начинают без старых непрочитанных сообщений.
- CHAT-08 — закрыто: новые строки RU/EN зарегистрированы до UI. Обучающие/служебные подсказки не добавлены; прежний messageUploadHint и его ключ удалены. Ошибки операций не отображают SQL/внутренние сообщения. ФИО/должность/роль — данные участника.
