# Спецификация генерации кодов учебных групп (Course Group Naming)

При создании учебных групп напрямую в базе данных агент обязан строго следовать данному регламенту.

## 1. Формат кода
Код группы имеет строгий формат:
`[ФИЛИАЛ-ИЛИ-ОНЛАЙН]-[КУРС]-[ТИП]-[ГОД]-[НОМЕР]`
*Пример:* `CYP-VC-GRP-26-0001`

### Блоки кода:
1. **Филиал / Онлайн**:
   - Короткий код филиала из его карточки (`academy_schools.short_code`, например `CYP` для Cyberpark).
   - `ONL` — онлайн-занятия (всегда используется `ONL`, независимо от физического местонахождения преподавателя). Код `ONL` зарезервирован и не может быть кодом филиала.
   - Код филиала задаёт администратор в настройках филиала: до 10 заглавных латинских букв и цифр, у каждого филиала свой.
2. **Курс**:
   - Короткий код курса из его карточки (`academy_courses.short_code`, например `VC`, `AI`): до 10 заглавных латинских букв и цифр, у каждого курса свой.
3. **Тип обучения**:
   - `GRP` — групповое обучение.
   - `IND` — индивидуальное обучение.
4. **Год**:
   - Последние две цифры года создания (например, `26` для 2026 года).
5. **Порядковый номер**:
   - Глобальный и уникальный среди **всех** учебных групп (независимо от филиала, курса, типа обучения и года).
   - Дополняется нулями слева до 4 знаков: `0001`, `0002`, `0003`...
   - Выдаётся последовательностью PostgreSQL `academy_group_code_seq`: следующее значение, но не меньше `max + 1` от наибольшего номера в названиях групп. Последовательность никогда не идёт назад, поэтому номер удалённой группы и номер неудачного создания больше не выдаются (возможны пропуски).

## 2. Алгоритм создания
1. Код собирает сервер (`server/modules/academy/group-code.ts`) под общей блокировкой расписания: коды филиала и курса из их карточек, номер — `setval('academy_group_code_seq', GREATEST(nextval(...), max + 1))`.
2. Предпросмотр кода (`GET /api/academy/group-code-catalogue`) показывает следующий номер, не занимая его.
3. При вставке групп напрямую в БД номер брать той же командой, а не вычислять вручную.

## 3. Запреты и ограничения
- **Запрещено** добавлять в код группы номер кабинета, имена, дни недели, время занятий, уровень или телефон (эти данные хранятся в отдельных полях).
- **Запрещено** вести отдельную независимую нумерацию по курсам, годам или филиалам.
- **Запрещено** повторно использовать номера архивных или удалённых групп.
- После создания код группы не изменяется при смене преподавателя, кабинета или расписания. При переводе офлайн-группы в постоянный онлайн создаётся новая группа с кодом `ONL`.
