# Состояние реализации LMS

Цель — полный объём [ТЗ](lms-student-parent-specification.md), включая F01–F18 и A01–A40. Исключены карта навыков и AI-помощник. Этапы не сокращают конечный объём.

Уточнение цели от 12 октября 2026 года: реализовать весь объём ТЗ, сохранив работоспособность действующей CRM; обеспечить отдельный запуск и независимое масштабирование API и фоновых обработчиков, с явными границами ответственности, ограничениями ресурсов и безопасной конкурентной обработкой задач. Выбирать стек каждого компонента по измеренной производительности и надёжности; менять реализацию отдельных обработчиков, когда проверяемый выигрыш оправдывает переход. Подтвердить результат функциональными проверками, нагрузочным профилем ТЗ, проверкой миграций и отката; работу распределять между всеми доступными агентами.

12 октября пользователь отдельно поручил немедленно отправить реализацию в `main`, выполнить необходимые миграции и снял строгие численные требования скорости с условий выпуска. Результаты измерений сохранены ниже; браузерная и учебная приёмка остаются отдельными условиями полного запуска.
