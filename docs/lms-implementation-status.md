# Состояние реализации LMS

Цель — полный объём [ТЗ](lms-student-parent-specification.md), включая F01–F18 и A01–A40. Исключены карта навыков и AI-помощник. Этапы не сокращают конечный объём.

Уточнение цели от 12 октября 2026 года: реализовать весь объём ТЗ, сохранив работоспособность действующей CRM; обеспечить отдельный запуск и независимое масштабирование API и фоновых обработчиков, с явными границами ответственности, ограничениями ресурсов и безопасной конкурентной обработкой задач. Выбирать стек каждого компонента по измеренной производительности и надёжности; менять реализацию отдельных обработчиков, когда проверяемый выигрыш оправдывает переход. Подтвердить результат функциональными проверками, нагрузочным профилем ТЗ, проверкой миграций и отката; работу распределять между всеми доступными агентами.

12 октября пользователь отдельно поручил немедленно отправить реализацию в `main`, выполнить необходимые миграции и снял строгие численные требования скорости с условий выпуска. Результаты измерений сохранены ниже; браузерная и учебная приёмка остаются отдельными условиями полного запуска.

Дополнительное уточнение 12 октября: группы и ученики не должны требовать поочерёдного ручного переноса. Общие карточки, зачисления и расписание уже читаются из CRM; добавлена автоматическая подготовка учебных разделов всех разрешённых групп через lifecycle worker. Новые группы подхватываются автоматически, код `CYP`/`ONL` задаёт формат, для старых названий доступен один общий явно выбранный формат. Черновики и закреплённые программы сохраняют историю и правки сотрудников. Проверка родительских связей и неоднозначных платежей не заменяется автоматическим угадыванием. Миграция `0137` разрешает явное системное происхождение новых черновиков и аудита, сохраняя прежних авторов и FK. Новое включение production-флагов, браузерная приёмка и пилот в этот инкремент не входят; пользователь попросил закончить изменениями в GitHub.

Проверки этого инкремента на Node 24: **317 файлов / 2714 тестов PASS**, без пропусков; `check`, `build`, `audit:security` прошли, secret scan проверил 1310 файлов. Новое поведение подтверждено PG/domain, DOM и чтением изменяемых CRM-карточек; настоящий браузер и отдельный compiled HTTP-стенд не запускались. Два старых notification-теста теперь явно задают даты очереди, отчёта, достижения и завершения по своим тестовым часам, устраняя зависимость от времени запуска. Миграция 0137 проверена локально; её production-применение и новый CI/deployment не выдаются за уже завершённые.
