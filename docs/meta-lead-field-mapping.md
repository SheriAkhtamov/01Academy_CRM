# Поля заявок Meta Instant Forms

Импорт распознаёт стандартные поля Meta и названия вопросов на русском,
узбекском и английском. Имя контакта, все распознанные корректные телефоны,
имя и возраст ребёнка, район, язык, дни и время обучения, цель и срочность
записываются в соответствующие поля карточки. Ответы и исходный payload Meta
сохраняются в `academy_lead_import_records.payload` независимо от распределения.

При повторной заявке заполняются только пустые поля (и автоматически созданное
имя «Новый контакт»). Внесённые менеджером значения сохраняются; отличающиеся
ответы остаются в комментарии. Уже сохранённые значения не дублируются.
Для новой заявки без подходящего поля, некорректного или неоднозначного ответа
сохраняется комментарий. Например, `8🏰` — возраст 8, `1991` не является
телефоном, а `Toshkent` не определяет конкретный район Ташкента.

## Исправление существующих заявок

Повторная доставка одного и того же Meta ID не переимпортирует заявку.
Для ранее сохранённых ответов есть отдельная адресная команда:

```sh
node dist/scripts/repair-meta-lead-fields.js --lead-ids=3536
node dist/scripts/repair-meta-lead-fields.js --lead-ids=3536 --apply
```

Первая команда работает в транзакции `READ ONLY` и возвращает количество
планируемых изменений. Вторая применяет их. Обязателен явный список CRM ID
(до 1000); список разделяется запятыми. Подключение берётся из обычной конфигурации
CRM. Перед запуском на удалённом сервере требуются предоставленные пользователем
доступы согласно `AGENTS.md`.

Команда заполняет пустые поля и добавляет телефоны. Комментарий изменяется,
только если совпадают прежний сгенерированный текст, время исходной заявки
и отсутствие автора; неоднозначные, изменённые и авторские комментарии
сохраняются. Пустой после распределения сгенерированный комментарий удаляется.
Даты оставшихся комментариев, исходные payload, менеджер, этап, курс и задачи
не меняются. Повторный запуск не добавляет телефоны или комментарии заново.
Перед применением следует сохранить резервную копию выбранных карточек.
