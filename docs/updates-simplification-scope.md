# Упрощение «Что нового» — область и приёмка

## Запрос и принятые решения

- Удалить категории обновлений полностью из активной модели: фильтры, бейджи, определение категории, редактор, черновики, переводы, общий контракт и API.
- Удалить блок «Всего релизов / Последний релиз».
- Удалить функцию массового прочтения обновлений, её обработчик, утилиту и переводы. Обычное прочтение отдельной статьи остаётся. Массовое прочтение общих уведомлений вне области.
- Удалить кнопки копирования ссылки и перехода в раздел из ленты, статьи и быстрого просмотра, а также ставшие ненужными обработчики, поле целевого раздела редактора и активное поле action контракта.
- Оформить страницу статьи отдельной Card: непрозрачный bg-card, рамка, скругление, адаптивные отступы, ширина чтения max-w-4xl. Не превращать существующие Dialog в inline-блоки.
- Удалить технические и служебные подсказки в затронутых сценариях; не добавлять новые поясняющие абзацы.
- Совместимость: исторический JSON может содержать category/action; API выдаёт статьи без них, повторная публикация сравнивает значимые поля и не создаёт дубликаты или повторные уведомления. Новые публикации не принимают удалённые поля. Исторические записи физически не переписывать; миграции не нужны и не запускаются.

## Пользовательские сценарии

1. Список обновлений: поиск, фильтр года, прочтение, быстрый просмотр в Dialog, статусы одного поста.
2. Статья по /updates?post=id: отдельная поверхность чтения, возврат в ленту, оглавление, изображения в Dialog, реакции, соседние посты.
3. Новый пост в Dialog: RU/EN, секции, предпросмотр, восстановление прежнего черновика, публикация и подтверждения удаления содержимого.
4. API списка, отдельного поста и публикации; прежние статьи, идемпотентность и уведомления публикации.

## Критерии приёмки

- Во всей области отсутствует активная система категорий обновлений и массовое прочтение постов.
- Нет указанных пользователем статистики и кнопок; нет пустых панелей после удаления.
- Статья семантически article и имеет отдельную поверхность чтения со свободным адаптивным пространством; длинный текст и изображения не расширяют колонку.
- Старые статьи и черновики открываются, новая публикация работает с RU/EN, повторная публикация не рассылает уведомления заново.
- Восстановление прежнего черновика учитывает заполненные sectionsEn, даже если sectionsRu пуст.
- Существующие модальные окна остаются модальными; удаление раздела/пункта/черновика имеет подтверждение.
- Нет хардкода пользовательских текстов; check:i18n проходит.
- Исполнители согласуют стыки напрямую до реализации и делают взаимную проверку diff после неё.
- Координатор запускает npx tsc --noEmit после каждого раунда кода, адресные тесты и обязательные статические проверки. Полный локальный набор не запускается.
- Браузер не открывать и скриншоты не делать без отдельного явного разрешения. DOM-тесты в jsdom разрешены, это не браузерные проверки.
- Независимый критик повторно проверяет все замечания и явно одобряет результат до завершения.
- Существующие несвязанные изменения сохраняются. Публикация задачи — main, без новой ветки. CI тесты/аудит/сборка не ослабляются.
